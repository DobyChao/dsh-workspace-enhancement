# R2 — UI 统一轮

## 目标

① 把「添加工作区」流与设置页的机器表单统一为**并集**（共享 `MachineForm`：认证 tabs + 别名/导入 +
HostKey 模式 + 加密开关 + 跳板链）；② 会话栏区分远程工作区并显示**三态在线状态**
（未知 / 活跃 / 离线），非活跃时提供「重新检测并尝试连接」。
需求 ID：CONTEXT §6.2「R2 UI 统一轮」；前身为 §7「UI 一致性」开放问题。

## 验证

- **单测**：73/73（t9 在**干净环境** `npm ci` 后独立复跑：35 boundary + 8 conn-status +
  9 machine-form + 3 row-badges + 4 keychain + 7 registry-view + 7 migrate）；typecheck 0 错误；
  build 成功（`client.js` 163.28 kB / gzip 36.38 kB）。
- **E2E（t4）**：表单一致性全 PASS（collapsed / advanced / 密码 tab 三态 DOM 对比 + 截图；
  按钮文案正确区分：设置页「保存/清空/测试连接」、flow「保存并浏览/取消/测试连接」；高级默认折叠；
  默认 port=22 / 用户名 root）；四态测试连接 PASS（key / 错误密码脱敏 / keychain 解析 / 无凭据回退）。
- **评审**：t5 **needs-fix**（唯一必改：`react-dom` 未声明——测试导入 `react-dom/server` 但
  `package.json` 无该依赖，干净 `npm ci` 后必 `ERR_MODULE_NOT_FOUND`）→ t8 修 → t9 **approve**。
- **运行态**：`client.js` 159 KB、零连接语义（未探测即不连接）。

## 结果

- 交付共享 `MachineForm`（两处入口同一套字段与提交语义）、会话栏远程标识（🌐）+ 三态徽标 +
  「重新检测并尝试连接」、`row-badges` DOM 增辉层（C1 设置页 / C2 flow / C3 会话栏）、
  `/dsw/conn.{status,probe,reconnect}` 三个 RPC 端点。
- F0 / F1 / F3 全修；失败连接缓存根治（`getClient` 失败后 `ready=undefined`，下次真重试）。
- 上线：已部署 3080（ROADMAP R2 行：✅ 上线）。
