# R61 — 准备发布 0.2.9

> 插件与远程组件同升 `0.2.9`。13 个 seam peer 追加 `^0.2.2-rc.1`，旧范围保留。
> 本轮不合并、不打 tag、不触发 npm publish。没有预留的 `PUB-*`，不新开待办 ID。

## 1. 目标

`PUB-13`（0.2.8）已经发布：tag `v0.2.8`，npm `latest` 是 `0.2.8`（2026-11-03）。
本轮把 master `fdd9a6a`（已含 #97）收成 `0.2.9`，并声明宿主 0.2.2-rc 家族。

## 2. 拆解

1. **版本**：`package.json` / lock、`CHANGELOG` 0.2.9 段、`core/artifact.json`、
   Go `coreArtifactVersion`、`npm run sync:core-manifest` 投影的 `src/core-artifact.ts`。
   插件与远程组件同为 `0.2.9`。版本门仍按 major.minor，同线 patch 不强制重部署。
2. **核心工件**：`node scripts/ensure-core.mjs` 重建 linux-x64 与 linux-arm64，
   新二进制 sha256 追加进 `compatHashes`（已发布哈希保留）。
3. **peer**：13 个 seam peer 从 `^0.1.7-rc.2 || ^0.2.0-rc.1 || ^0.2.1-rc.1` 扩为
   `^0.1.7-rc.2 || ^0.2.0-rc.1 || ^0.2.1-rc.1 || ^0.2.2-rc.1`。
   devDependencies 仍是 `^0.1.7-rc.2`。`@deepseek-ai/cordis`、`@deepseek-ai/schemastery`、
   `dsh-better-sidebar` 不动。`^0.2.2-rc.1` 的 caret 覆盖同 tuple 的更晚预发布
   （例如 `0.2.2-rc.2`），不含 `0.2.2-alpha.*`。
4. **哨兵**：`next` 已在装 `0.2.2-rc.1`（宿主 `latest` 同版本）。`next` 离开 0.2.1 后
   `upstream.yml` 增加 `pinned-0.2.1-rc.1`，与 `pinned-0.2.0-rc.1` 同一套精确版本安装。
5. **本版收录**（已在 master `fdd9a6a`）：[#97](https://github.com/DobyChao/dsh-workspace-enhancement/pull/97)
   `SshFileSystem` 实现 `patchText` / `deleteFile` / `moveFile`（Fixes #93 / #91），
   写路径与 `writeText` 相同（引擎 + `confinedWriter`）。这是 npm `0.2.8` 相对
   `@deepseek-ai/dsh@0.2.2-rc.1` `FileSystem` 缺的三个抽象成员。
6. **待办**：`PUB-13` 记为 shipped。不新开 `PUB-*`。`UPSTREAM-14` 仍 doing，备注改为
   #97 已合入、peer 随 0.2.9 追加。本 PR 不打 tag、不发布、不 Approve。

## 3. 验证

`npm run preflight`：node / npm / git / gh 可用；本机已是 Linux（WSL 探测缺失，不挡本轮）；
无新 UI，不跑 browser-use。再跑 `npm run check:static`、`typecheck`、`npm test` 与
`go test ./...`（`core/`）。linux-x64 二进制 `dsh-core version` 应报 `0.2.9`。
