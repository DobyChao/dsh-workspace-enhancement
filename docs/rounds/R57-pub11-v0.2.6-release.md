# R57 — PUB-11：准备发布 0.2.6

> 插件与远程组件同升 `0.2.6`。peer 范围不动。本轮不合并、不打 tag、不触发 npm publish。

## 1. 目标

`PUB-10`（0.2.5）已经发布：tag `v0.2.5` 在 `3b633dd`，npm `latest` 是 `0.2.5`，backlog 仍停在 doing。
本轮把它标 shipped，并把 `v0.2.5` 之后已在 master 的改动收成 `0.2.6`。

## 2. 拆解

1. **版本**：`package.json` / lock、`CHANGELOG` 0.2.6 段、`core/artifact.json`、
   Go `coreArtifactVersion`、`npm run sync:core-manifest` 投影的 `src/core-artifact.ts`。
   插件与远程组件同为 `0.2.6`。版本门仍按 major.minor，同线 patch 不强制重部署。
2. **核心工件**：`node scripts/ensure-core.mjs` 重建 linux-x64 与 linux-arm64，
   新二进制 sha256 追加进 `compatHashes`（已发布哈希保留）。
3. **peer 不变**：13 个 seam peer 仍是 `^0.1.7-rc.2 || ^0.2.0-rc.1 || ^0.2.1-rc.1`。
   不改 `upstream.yml`，不重写 tag / composition 基线。
4. **本版收录**（均已在 master）：[#80](https://github.com/DobyChao/dsh-workspace-enhancement/pull/80)
   远程文件页与浏览器终端路由（`BUG-16` / `BUG-17`）；
   [#81](https://github.com/DobyChao/dsh-workspace-enhancement/pull/81) 弹窗拖选关闭与路径 Esc；
   [#82](https://github.com/DobyChao/dsh-workspace-enhancement/pull/82) 选择器静音外观，以及远程终端改走
   exec+PTY，不再把清理后的环境变量写进登录 shell（`BUG-19`）。
5. **待办**：`PUB-10` → shipped。`BUG-16` / `BUG-17` 从「待 CI/合并」改 done（#80 已在 master）。
   `PUB-11` doing：合并后所有者打 `v0.2.6` 并 Approve `npm-publish`。本 PR 不做这两步。

## 3. 验证

本地 `npm run check:static`、`typecheck`、`test:agent`。core 用本机 Go 1.22 重建并登记 sha。
完整 `npm test` / pack 由 CI 跑。无新 UI，不跑浏览器。

## 4. 结果

0.2.6 包装在一个 PR 里。tag、Release、npm `latest` 在合并并 Approve 之后才存在。

## 5. 遗留

- 合并后所有者打 `v0.2.6` 并在 Actions 里 Approve `npm-publish`。本轮不打 tag、不点 Approve。
- 同 major.minor 不强制重部署。本版 Go 只改 `coreArtifactVersion`。
