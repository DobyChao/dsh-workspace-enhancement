# R6（I18N）— 运行时国际化：三面全量双语

## 目标

把插件的**三面**——客户端 UI、宿主「远程认知」系统提示、`sw_*` 工具面（描述/参数/输出/错误）
——全部接入框架 `ctx.locale` 体系，复用设置页 Language 行（不新增语言 UI），实现 zh/en 双语。
需求 ID：**CONTEXT §5.12 / ROADMAP R6（I18N）**；设计见 `drafts/i18n-design.md`（不入库）。

关键设计决策（t3）：命名空间 **`dsw`**（`workspace` 已被官方 `dsh-client-ui-workspace` 占用，
重复 register 会抛错）；单一共享词典 `src/locale/`；zh 键集为真源 + en 编译期完整性校验；
宿主语言 = `settings.locale.preference ?? 'en'`（每次求值即时读，settings 可选、无缓存）；
工具描述/参数 **getter 化**（路线 B，官方 `run_code` 范式）；`row-badges` DOM 层**就地重绘**。
