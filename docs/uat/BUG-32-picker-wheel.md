# UAT：BUG-32 — 目录选择器滚轮不透传

> 流程与 lab 用法见 [README.md](./README.md)。单测盖住遮罩拦截 wheel 冒泡、以及滚动容器的
> `overscroll-behavior: contain`。这里只走浏览器里的滚轮。

## 0. 基本信息

| 项 | 值 |
|---|---|
| 验收对象 | 「选择工作区目录」里的连接列表和目录列表 |
| 需求 / 缺陷 ID | `BUG-32` |
| 预期耗时 | 5 分钟 |

## 1. 前置条件

| 项 | 值 |
|---|---|
| lab 地址 | `http://127.0.0.1:50599/`（`scripts/dev-lab.ps1`） |
| 其他前置 | 已保存连接或 `~/.ssh/config` 主机足够多，使左侧列表超出对话框；本机家目录子文件夹足够多，使右侧列表超出对话框 |

## 2. 步骤

1. 侧栏点「添加工作区」，打开「选择工作区目录」。
2. 鼠标停在左侧连接列表上，向下滚动滚轮。
   - [ ] 左侧列表自己滚动。
   - [ ] 对话框后面的侧栏和会话页不动。
3. 滚到左侧列表底部后继续滚。
   - [ ] 后面的页面仍然不动。
4. 鼠标停在右侧目录列表上，重复步骤 2 和 3。
   - [ ] 右侧列表自己滚动，滚到底后面的页面不动。
5. 从会话标题栏「工作区」里点「浏览…」再打开同一个选择器，重复步骤 4。
   - [ ] 目录列表自己滚动，后面的会话页不动。
