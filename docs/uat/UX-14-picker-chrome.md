## 2. BUG-18 拖选不关窗

1. 打开「选择工作区目录」，点「新建连接」。
2. 在主机名输入框里按住左键，向左拖出对话框，在变暗的背景上松开。
   - [ ] 「新建远程连接」不关闭，已输入的内容还在。
3. 在对话框外的变暗背景上按下并松开（起点和终点都在背景上）。
   - [ ] 对话框关闭，下面的目录选择器还在。
4. 再打开新建连接，按 Esc。
   - [ ] 只关新建连接，目录选择器还在。
5. 目录选择器里对「新建文件夹」、删除连接、添加 SSH 主机的确认框各做一次步骤 2。
   - [ ] 拖出对话框再松开，确认框不关闭。

## 3. UX-14 目录选择器

1. 左侧已保存连接里，名称或 `user@host` 被省略号截断的那一行，悬停名称和地址。
   - [ ] 提示是完整名称，以及完整的 `user@host:port`。
2. 点右侧面包屑的最后一段，或点铅笔按钮。
   - [ ] 面包屑变成输入框，里面是当前完整路径。
3. 改成另一条存在的绝对路径，按回车。
   - [ ] 文件列表跳到该目录。远程路径可以不写开头的 `/`，也会按绝对路径打开。
4. 再打开输入框，改几个字，按 Esc。
   - [ ] 输入框消失，目录停在回车之前的位置。
5. 拖左右分区之间的竖线。
   - [ ] 左侧连接列表和右侧文件列表一起变宽变窄，松手后保持。关掉选择器再打开，宽度还在。

## 4. UX-15 刷新图标

1. 看侧栏远程工作区行、目录选择器里的连接行、一个远程会话的头部、设置页的机器行。
   - [ ] 原来的「重新检测」或「重连」都是一枚刷新图标，旁边不再有这两个词。
   - [ ] 悬停图标仍说明要重新检测并尝试连接。
2. 点其中一枚。
   - [ ] 状态回到「检测中」，结束后仍是「可连接」或「不可连接」，图标还在。

## 5. UX-16 工作区悬停

1. 悬停侧栏里一个远程工作区，停大约一秒。
   - [ ] 卡片仍有工作区名和创建时间。
   - [ ] 路径行是服务器（`user@host:port`，有别名时带别名）和远端真实目录（以 `/` 开头），不是 `dsw-routes` 下面的本机占位路径。
2. 悬停一个本机工作区。
   - [ ] 路径仍是本机目录，不被改写。
