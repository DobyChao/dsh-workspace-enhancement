# UX-17 — 设置页「设为默认」与本机行

lab（Windows 路径由本机另跑）。没有浏览器时，单测覆盖默认起始与本机行的动作限制。

存储键仍是 `currentId`。本机的 id 是保留名 `local`，不会写进机器表。

## 文案

1. 打开远程工作区设置。「已配置的机器」里每一台远程机器的按钮是「设为默认」，不再是「设为当前」。
2. 点一台远程机器的「设为默认」。绿色横幅点名这台机器，并说明未指定连接时新建工作区从这里开始。该行有选中描边，标签是「默认」。

## 本机行

1. 列表里始终有一行「本机」，副文案是「这台电脑上的目录」。没有远程机器时也在。
2. 本机行没有「编辑」，也没有「更多」（因此没有忘记指纹、远程组件状态、部署远程组件、删除）。
3. 本机还不是默认时，行上有「设为默认」。点它之后，本机行出现「默认」标签，按钮消失。
4. 从主入口打开目录选择（不预选连接）。右侧浏览本机目录，而不是刚才那台远程机器。
5. 从某一台机器的侧栏入口打开目录选择时，仍从那台机器开始，不被本机默认覆盖。
6. 再把一台远程机器设为默认。未指定连接的目录选择回到那台机器。本机行重新出现「设为默认」。

## 不覆盖

- 本机行不测 SSH、指纹或远程组件部署。这些动作不在这一行上。
- 已有远程机器的编辑、删除、部署失败样式仍按 [UX-11 / UX-12](./UX-11-12-settings.md)。按钮文案自本项起是「设为默认」。
