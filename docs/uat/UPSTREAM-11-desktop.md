## 1. 前置条件

| 项 | 值 |
|---|---|
| 桌面版 | 官方桌面应用（**用户安装**；勿装 npm 社区占位包 `dsh-desktop`，见 compatibility §7.1） |
| 桌面版本 | `<设置/关于里的版本号>`（预期与宿主家族同版本同日） |
| 首启完成 | 桌面至少启动过一次（`<DSH_HOME>/profiles/desktop` 已出现） |
| 插件产物 | `npm run build` → `npm pack` tarball 一个（桌面 Plugins 页选文件安装） |
| ssh 目标 | 一台可 ssh 机器（建议 WSL sshd，同 [`matrix.md`](./matrix.md) §1） |
| 对照端 | 一处 web 端 DSH（lab 50599 或产品 3080），仅 D8 用 |
| **备份** | **先备份 `<DSH_HOME>` 的 `remote-workspaces/machines.json` / `known_hosts.json`**（D8 动真实注册表） |

**禁止**：手工编辑 desktop profile 的 `cordis.patch.yml`（装/卸一律走桌面 Plugins 页）；真实凭据进仓库/截图；未备份跑 D8。

> 可选隔离探针（未核实项）：启动桌面进程前设 `DSH_HOME=<scratch>`，若桌面尊重它则整场 UAT 可隔离；若仍落真实 home ⇒ 记「不尊重」，按备份执行。
