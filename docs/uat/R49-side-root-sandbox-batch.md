## 5. 备注

- 步骤 2 / 5 是 `REQ-I24` 剩下的唯一未知：Windows ACL 后端每个工作区根一条持久授权，首次授权下发
  整棵树（同步，期间宿主所有会话卡住），卸载不撤销 ACE；子目录会继承 Everyone 拒 `FILE_DELETE_CHILD`，
  留意副根里普通工具（资源管理器删除、git）是否受影响。若不可接受，回到 ADR-0028 §5 讨论。
- 步骤 3 只能在副根第一次跑命令时触发授权；只用文件工具不会动 ACL。
- 验收后清理 `D:\lab\*`、lab 注册表里的 `c1`/`c2`，确认 50599 已停止。
