# BUG-16/17 — 远程文件预览与浏览器终端

仅在隔离 lab（DSH_HOME=.dsh-lab，50599）执行，先 build → pack → 插件管理器 remove/add tarball → 重启。

## 文件

1. 远程会话 cwd 保持占位路由。在对应远端工作区准备普通标记文本、上传目录文件和带空格/中文的文件名。
2. 不启用 better-sidebar，打开原生「工作区文件」页：路径条应显示远端路径；目录行仍可见，普通文本可从树中点击打开。内部树键和会话 cwd 仍是占位路径。远程 watch 不可用时手动重新读取。
3. 点击工作区文件或已有会话文件引用：独立远程预览打开，正文可见，不报本地 ENOENT。
4. 启用 better-sidebar 0.28.0 重复打开会话文件引用，正文仍可见；本地会话文件继续使用原编辑器。
5. 不把 better-sidebar 自己的文件树列举算作已通过：0.28.0 仍读本机占位目录，这一差异需上游 PR（调查文档 §3）。
6. 切换会话、关闭预览后不应出现前一文件正文；图片/PDF 使用有界预览，大文件仍有截断/无法预览提示。

## 终端

1. 在远程会话打开「新建终端」：应为远端可用 shell，不能出现 cmd.exe/pwsh 路径或「终端错误：null」。
2. 输入 pwd、uname -s：显示远端工作区和 Linux；确认输入与输出可用。
3. 「选择 Shell」可以列举可用远端 shell，不存在的 Windows 候选不使整个列举失败。
4. 本机会话新建终端仍是本机环境。两台远端同时打开时各自保持自己的 cwd 和 shell。
5. 取消分配/断开网络应返回错误，不静默回落到本机；关闭本轮终端，恢复本轮临时启用的 bundle 状态。
