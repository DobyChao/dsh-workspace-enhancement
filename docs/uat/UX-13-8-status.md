## 2. 步骤

| # | 操作 | 期望 | 观察点 | 结果 |
|---|---|---|---|---|
| 1 | 打开左侧栏，展开含远程工作区的分组 | 行上很快出现可达性徽章，不必先点 | 文案从「检测中」变成「可连接」或「不可连接」。不再出现「未检测」，也不把探测结果写成「已连接」 | ☐ 通过 ☐ 不通过 |
| 2 | 看徽章所在行 | 徽章在它自己的远程行上 | 同名的本地工作区行没有这枚徽章。DOM 上远程分组行有 `data-row-key="workspace:…"`，徽章的 `data-dsw-conn-id` 对应该机器 | ☐ 通过 ☐ 不通过 |
| 3 | 打开一个远程会话 | 会话头「远程状态」自己开始探测，并且有「重新检测」按钮 | 同样是检测中 → 可连接 / 不可连接。按钮在这三种文案旁边都在，不会等结果出来就消失。本地会话不出现这块 | ☐ 通过 ☐ 不通过 |
| 4 | 在「可连接」「不可连接」或「检测中」时点「重新检测」 | 三种状态按钮都在；点下去立刻再探，不要求先等自动退避结束 | 侧栏行、添加工作区里的徽章、会话头「远程状态」块里都有这颗按钮。点下去文案回到「检测中」，结束后回到可连接或不可连接，按钮仍在 | ☐ 通过 ☐ 不通过 |
| 5 | 设置页语言切到 English | 三态跟着变 | Checking / Reachable / Unreachable。「重新检测」变为 Re-check，三种状态都还在。会话里「已连接的机器」仍是 Connected machines，不跟可达性混用 | ☐ 通过 ☐ 不通过 |
| 6 | 添加工作区侧栏里的已保存连接 | 打开侧栏就探测，不必先点徽章 | 每台机器一行一个徽章，文案是上面三态之一。「重新检测」（紧凑行上是「重连」）在结果出来后仍在 | ☐ 通过 ☐ 不通过 |
| 7 | 同一面板里看「SSH 配置主机」（例如 c1、c2） | 打开面板就探测，不必先把该主机存成连接 | 每一行有徽章，文案从「检测中」变成「可连接」或「不可连接」。没有用户名的 Host 显示「不可连接」，不会因此多出一条已保存连接。打开面板本身不往 known_hosts 写入未见过的主机密钥；已记录的密钥对不上则显示「不可连接」，悬停提示「主机密钥已变更」（英文 Host key changed），和网络不通的提示分开 | ☐ 通过 ☐ 不通过 |
