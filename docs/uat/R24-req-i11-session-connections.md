## 2. 步骤

| # | 操作 | 期望 | 观察点 | 结果 |
|---|---|---|---|---|
| 1 | 新建**本地**会话（零连接），问模型「有哪些远程机器可用」并让它调用 `sw_exec` | 工具面与提示面均为零 | `sw_exec` 返回明确错误：本会话未连接任何机器、请先 `sw_connect`；会话系统提示里**没有** `sw-remote` / `sw-exec` 段落；`session.conn.list` 返回 `items: []` | ☐ 通过 ☐ 不通过 |
| 2 | 让模型调用 `sw_connect(machines:["c1"])` | 连接成功 | 工具输出**逐行列出** `c1`（id + `user@host` + 可达）；`session.conn.list` 返回 `["c1"]`；会话系统提示下一次 assembly 出现已连接机器清单 | ☐ 通过 ☐ 不通过 |
| 3 | 同会话调用 `sw_exec(server:"c1")` 执行 `uname -a` | 允许 | 正常返回远端输出 | ☐ 通过 ☐ 不通过 |
| 4 | 同会话调用 `sw_exec(server:"c2")`（已注册、**未连接**） | 拒绝且可自愈 | 错误列出**本会话已连接**的 id（`c1`）；不执行任何命令 | ☐ 通过 ☐ 不通过 |
| 5 | 调用 `sw_connect(machines:["nope"])`（注册表里没有） | 拒绝 | 错误为「未知机器」并**列出已知 id** | ☐ 通过 ☐ 不通过 |
| 6 | 会话 header「⊕ 工作区」打开面板 | 面板 = 会话工作区驾驶舱 | 三段可见：主工作区、副工作区（可挂/卸）、**已连接的机器**（含开关）；未连接时显示空态文案；中文与 English 两套文案都正确（切语言复看） | ☐ 通过 ☐ 不通过 |
| 7 | 在面板里**打开** `c1` 开关 | UI 与工具面同源 | `session.conn.list` 变为 `["c1"]`；同会话 `sw_exec(server:"c1")` 立即可用；**反向**：用 `sw_connect(machines:[])` 断开后刷新面板，开关回到关闭 | ☐ 通过 ☐ 不通过 |
| 8 | 本地会话用**官方文件工具** read `ssh://c1/etc/hostname` | 注册表级路由生效 | 读出远端内容；**无需**先声明副根 | ☐ 通过 ☐ 不通过 |
| 9 | 原子性：把 `c1` 的端口/主机改成**不可达**后再 `sw_connect(machines:["c1"])` | 报错且**不改状态** | 调用抛错并给出不可达详情；`session.conn.list` **保持**调用前的值（不被清空、不被写入） | ☐ 通过 ☐ 不通过 |
| 10 | 红线 1 取证：grep 会话日志（`tool/call` 事件的 `arguments`） | 凭据永不入日志 | 全文无 `password`（以及 `privateKeyPath`）字段；`sw_connect` 的参数面只有 `machines` | ☐ 通过 ☐ 不通过 |
| 11 | 重启 lab（`dev-lab.ps1`），回到同一会话 | 连接集合跨重启保持 | `session.conn.list` 仍返回重启前的集合；状态文件为 `<lab home>/dsw-session-connections.json`，内容**只有机器 id**（无凭据字段） | ☐ 通过 ☐ 不通过 |
| 12 | 分层检查：`c1` 设 `remoteApproval: human`，已连接状态下执行远程命令 | 粗门与细门正交 | 审批卡照常出现（ADR-0020 未被连接动作取代）；**断开**连接后 `sw_exec` 直接被粗门拒绝（不进审批流程） | ☐ 通过 ☐ 不通过 |
| 13 | 副根共存：先挂一个副根，再做连接/断开动作 | 两套状态互不干扰 | `session.ws.list` 全程不变；断开到 0 后台面板仍显示副根清单 | ☐ 通过 ☐ 不通过 |
| 14 | **中插取证**（ADR-0021 §2.8）：步骤 2 连接 `c1` 后，**不新建会话**，在同一会话里再发一句话让模型复述它当前可用的远程机器 | 模型在会话中途看得到状态变化 | 模型回答里出现 `c1`；且该信息来自**运行时上下文快照（user-role）**而非纯头部 prompt —— 取证方式：查看该轮请求的上下文快照内容（`session.conn.list` 为 `["c1"]` 时快照应含机器清单）；断开后再问一次，清单随之消失 | ☐ 通过 ☐ 不通过 |
| 15 | **诚实边界取证**（ADR-0021 §2.7，**预期会被绕过**）：新建一个零连接的本地会话，让模型调用**官方 `bash` 工具**并传 `workdir: "ssh://c1/<工作区>"` 执行 `hostname` | 命令**会执行成功**（粗门只在工具层，官方工具按 cwd 路由） | 远端主机名返回；本项**不是缺陷**，需确认 ADR 与 README 已如实写明「exec 粗门可经官方工具 + `ssh://` workdir 绕过，命令级仍受审批门约束」；若该机器开着 `remoteApproval`，应同时出现审批卡 | ☐ 通过 ☐ 不通过 |

## 5. 备注

- **诚实边界（ADR-0021 §2.7）**：fs 面是**可见性门控**、不是强制围栏——模型只要拼出 `ssh://<id>/<path>` 就能经官方文件工具到达**任何已注册**机器（步骤 8 正是这条）。强制层只有 ADR-0020 的 spawn 审批门与（落地后）ADR-0022 的远端围栏，二者都只围**经 spawn 的命令**；fs 写面不在任何围栏内。文档与提示词不得写成「已围栏」。
- **信任根**：连接集合的上界是「用户把机器注册进注册表」这一动作；模型能在这个上界内扩展自己的执行面，这是设计意图，也是本项需要用户知情的地方。
- 验收后请清理：把会话连接清空（`sw_connect(machines:[])`）、恢复 `c1` 的可达配置、按需删除 `dsw-session-connections.json` 中的测试会话项，并确认 50599 已停止。
