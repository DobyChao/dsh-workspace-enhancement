## 2. 步骤

| # | 操作 | 期望 | 观察点 | 结果 |
|---|---|---|---|---|
| 1 | lab 内新建**本地**工作区会话，向模型提问「你的系统提示里有没有关于 `sw_exec` 或远程工作区的段落？」 | 没有 | 模型回答中不出现 `sw_exec` / 远程工作区提示的段落；`sw_remote` 段不存在 | ☐ 通过 ☐ 不通过 |
| 2 | 新建**远程**工作区会话（cwd 为 `ssh://c1/…`），问同一问题 | 有，且为**英文** | 回答中出现 `Remote workspace session` / `run on another server use \`sw_exec(server, command)\`` 等英文段落 | ☐ 通过 ☐ 不通过 |
| 3 | 在步骤 2 的会话里让模型执行 `sw_status` | 缺件提示为英文 | 工具输出中 `Remote is missing …` 等英文行；不再出现中文提示 | ☐ 通过 ☐ 不通过 |
| 4 | 设置页把界面语言切到 **English**，重开步骤 1、2 两个会话 | 与中文界面下**完全一致** | 本地会话仍无该段；远程会话仍为同一段英文（文案逐字相同） | ☐ 通过 ☐ 不通过 |

## 5. 备注

- **有意代价**（`ADR-0014` 代价④，t6 评审 F2）：本地会话不再收到 `sw_exec` / win32 bash 两段提示，模型只能从工具清单发现 `sw_exec`；工具本身仍注册、仍可显式调用。本脚本步骤 1 正是验收这一点。
