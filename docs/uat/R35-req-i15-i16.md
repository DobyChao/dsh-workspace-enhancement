## 2. 步骤

| # | 操作 | 期望 | 结果 |
|---|---|---|---|
| 1 | 无核心（或无 bwrap），打开远程 Linux 工作区，发一句纯聊天 | 会话能进；不因项目根探测失败整轮拒绝 | ☐ |
| 2 | 同一会话官方 Read 工作区内一既存文件 | **成功** | ☐ |
| 3 | 官方 Write 同一目录一新文件 | **拒绝**（`SANDBOX_UNAVAILABLE` 或围栏文案）；远端文件不存在 | ☐ |
| 4 | 官方 Bash / win32 `bash`：`echo hi` | **拒绝**，不得在远端跑出 `hi` | ☐ |
| 5 | `/permission danger-full-access` 后再 Write | **成功**（danger 仍走 SFTP） | ☐ |
| 6 | Windows 本地会话：看工具清单 | **没有** `bash`（有 `pwsh` / `sw_exec`） | ☐ |
| 7 | 添加 Linux 远程工作区，新开会话 | 工具清单**有** `bash`；`uname -s` 在远端成功（有核心或 danger） | ☐ |

步骤 6–7 只在 Windows 宿主上计分；POSIX 宿主标 N/A。
