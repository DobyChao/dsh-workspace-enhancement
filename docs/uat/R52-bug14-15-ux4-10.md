## 2. BUG-14 拖选不关窗（两处弹窗各一遍）

1. 打开目录选择器（连接侧栏 → 浏览，或会话内「选择远程目录」）。
2. 在弹窗**内部**的路径栏/文件名上按住左键拖选一段文本，**拖到弹窗外**的背景上松开鼠标。
   - [ ] 弹窗**不关闭**，浏览状态保留，选中内容可见。
3. 点弹窗背景空白处（按下与松开都在背景上）。
   - [ ] 弹窗正常关闭。
4. 按 Esc：弹窗关闭（回归不变）。
5. 会话内副工作区面板（side-workspaces 卡片）重复 2–3。

## 3. UX-10 表单不预填 + 警告时机

1. 新建远程连接表单。
   - [ ] 用户名栏为空，占位提示「如 root」；默认工作区栏为空，占位提示仍在。
   - [ ] 打开瞬间**无任何**红色校验警告。
2. 填主机名后失焦（可配 ~/.ssh/config 别名触发自动识别）。
   - [ ] 识别填充用户名/端口/私钥，但**工作区不被猜成** `/home/<user>`。
3. 不填用户名直接点「测试连接」。
   - [ ] 提示「请先填写登录用户名」，不发起 root@host 连接。
4. 设置页：完整填写并**保存成功**一台机器（settings 模式）。
   - [ ] 保存后表单重置为空白，且**不会**立即冒出「请填写主机名」（UX-5）。
5. 重新打开这台机器的编辑页。
   - [ ] 字段正常回填，打开瞬间无警告；改动或提交后才出现校验。

## 4. UX-4 状态点双主题

1. 连接列表中找到一台 active（绿点）与一台 offline/unknown 的机器（没有真机可断开一台制造 offline）。
2. 宿主切浅色 / 深色主题各看一遍。
   - [ ] 侧栏 DOM 增辉行与 React 徽章的圆点颜色**一致**，且随主题切换变化（不再是固定 hex）。
   - [ ] 深色下三态点均可辨（无融为一体/看不清）。

## 5. BUG-15 沙箱车道（代理可在 DSH 沙箱内自验）

1. 在 DSH 文件沙箱（workspace-write）里跑 `npm run check:static`，确认输出含
   `built core binary is registered in compatHashes — <sha>`（真跑，不是跳过）。
2. 破坏性对照（可选，验完还原）：把 `core/dist/<artifact>.tar.gz` 改名一分钟再跑一次。
   - [ ] `check:static` **红**并报「cannot run tar / extracted no dsh-core member」，不是静默跳过。
   - [ ] 还原后复绿。
