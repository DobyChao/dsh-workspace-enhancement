# ADR-0032：远程会话的上传落到远端工作区

- 状态：**accepted**（2026-10-14，用户拍板，REQ-I28）
- 相关：ADR-0021（会话 cwd）、ADR-0024（SFTP 部署同一条传输）

## 决定

远程会话（cwd 能路由到一台已保存的机器）里，用户上传的文件在上传回执返回**之前**，用 SFTP 写到该会话远端工作区的 `.dsh-uploads/<tag>-<leaf>`。复制失败则这次上传失败，不静默留在本机。

本地会话不复制。

工作区内已经存在的生成产物只把路径写进运行时上下文。工作区外、且本机磁盘上真有的绝对路径，复制到同一工作区的 `.dsh-artifacts/`。不另做文件浏览器（那是 REQ-A6）。

## 不做

- 只留本机附件、再架一条读取桥。
- 只做 spike、不接到上传回执。
- 替换 `ctx.attachments`（Cordis 服务身份）。包装宿主 `fileUploads`，卸载时还原。
